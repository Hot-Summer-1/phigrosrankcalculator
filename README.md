# Phigros S / V 评级计算器

输入物量与 ACC，计算取得 Phigros **S 评级（920000）** 与 **V 评级（960000）** 所需的最小最大连击数。

## 功能

- 同时给出 S、V 两个评级所需的最小连击数与连击占比。
- 自动判断当前 ACC 能否取得对应评级，不足时给出提示。
- 参考表列出各 ACC 下 S / V 评级所需的最小连击。
- 适配深色 / 浅色主题与移动端。

## 计分公式

```
分数 = 900000 × ACC + 100000 × (最大连击 / 总物量)
```

由此可得各评级的理论最低 ACC（全连时）：

| 评级 | 分数线 | 理论最低 ACC |
| --- | --- | --- |
| S | 920000 | 91.12% |
| V | 960000 | 95.56% |
